# Part 3: OAuth 2.0

**Entry prerequisites:** Foundations and the SAML Core progression.

**Core completion outcome:** Follow delegated and application access, configure its contract, renew credentials, and diagnose failures.

Follow the Core entries in order. Optional entries can be skipped. Lesson files are created as they are drafted; Planned titles are intentionally unlinked.
